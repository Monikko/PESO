## 🚨 TROUBLESHOOTING: Button Not Working

### **Problem: Nothing happens when clicking Print Report**

---

### **Solution 1: Check for Pop-up Blocker**

**Symptoms:**
- Click button → nothing happens
- No new window opens
- No error message

**Fix:**
1. Look for pop-up blocker icon in address bar
2. Click on it
3. Select "Always allow pop-ups from this site"
4. Try clicking Print Report again

**Browser-specific:**

**Chrome/Edge:**
- Look for 🚫 icon in address bar (right side)
- Click → "Always allow pop-ups from peso-theta.vercel.app"

**Firefox:**
- Look for information icon (i) in address bar
- Click → Permissions → Pop-ups → Allow

**Safari:**
- Safari menu → Preferences → Websites → Pop-up Windows
- Find your site → Select "Allow"

---

### **Solution 2: Check if There Are Applicants**

**Symptoms:**
- Alert message: "No applicants to print!"

**Fix:**
1. Make sure you're in the correct tab (Palayan City or Other Places)
2. Check if the applicants table shows data
3. If table is empty → No registered applicants yet
4. Register at least one applicant first

---

### **Solution 3: Check Browser Console for Errors**

**Steps:**
1. Open browser console:
   - **Windows:** Press `F12` or `Ctrl + Shift + J`
   - **Mac:** Press `Cmd + Option + J`
2. Click "Console" tab
3. Click "Print Report" button
4. Look for red error messages

**Common errors:**

**Error 1: "window.open is not defined"**
- This shouldn't happen in browsers
- Try different browser

**Error 2: "Popup blocked"**
- See Solution 1 above

**Error 3: "Cannot read property..."**
- Clear browser cache
- Refresh page (Ctrl+F5 or Cmd+Shift+R)

---

### **Solution 4: Try Different Browser**

**Test in order:**
1. ✅ Chrome (Best compatibility)
2. ✅ Edge (Good compatibility)
3. ✅ Firefox (Good compatibility)
4. ⚠️ Safari (May have restrictions)

---

### **Solution 5: Clear Cache and Reload**

**Steps:**
1. **Chrome/Edge:**
   - Press `Ctrl + Shift + Delete` (Windows)
   - Press `Cmd + Shift + Delete` (Mac)
   - Select "Cached images and files"
   - Click "Clear data"

2. **Firefox:**
   - Press `Ctrl + Shift + Delete`
   - Select "Cache"
   - Click "Clear Now"

3. **After clearing:**
   - Close all browser tabs for the site
   - Reopen site
   - Login again
   - Try Print Report

## 💡 TIPS:

### **1. Save as PDF Instead of Printing**
- When print dialog opens
- Select "Save as PDF" as destination
- Click Save
- File downloads to your computer
- Can email or archive the PDF

### **2. Print Preview Before Printing**
- Print dialog shows preview
- Check if all data is visible
- Verify formatting looks good
- Cancel if something looks wrong

### **3. Print Multiple Tabs**
- Print Palayan City report
- Switch to "Other Places" tab
- Print Other Municipalities report
- Now you have both reports!

### **4. Apply Filters Before Printing**
- Use filters to narrow down applicants
- Example: Only approved applicants
- Example: Only specific barangay
- Click Print → Only filtered applicants print
