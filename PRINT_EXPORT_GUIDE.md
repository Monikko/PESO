## 🔍 TROUBLESHOOTING

### **Can't find the buttons?**
**Solution:**
1. Make sure you're logged in as admin
2. Scroll down past the pie chart
3. Look for "Registered Applicants" section header
4. Buttons are at **TOP RIGHT** of that section
5. Should see blue button on left, green button on right

### **Print window doesn't open?**
**Solution:**
1. Check if pop-ups are blocked in browser
2. Allow pop-ups for peso-theta.vercel.app
3. Try different browser (Chrome recommended)
4. Check if print dialog is minimized

### **CSV won't download?**
**Solution:**
1. Check browser's download settings
2. Allow downloads for peso-theta.vercel.app
3. Check Downloads folder
4. Try different browser

### **Print is blank or missing data?**
**Solution:**
1. Make sure filters aren't too restrictive
2. Check if there are applicants in the list
3. Clear filters and try again
4. Refresh page and try again
